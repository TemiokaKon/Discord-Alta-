# Звуковые файлы Alta52

Поместите следующие звуковые файлы в эту папку:

## Необходимые файлы

1. **incoming-call.mp3** - Звук входящего звонка
   - Длительность: 3-5 секунд (зацикленный)
   - Характер: Мелодичный, приятный
   - Громкость: Средняя

2. **message.mp3** - Звук нового сообщения
   - Длительность: 0.5-1 секунда
   - Характер: Тихий, ненавязчивый
   - Громкость: Низкая-средняя

3. **notification.mp3** - Общее уведомление
   - Длительность: 0.5-1 секунда
   - Характер: Приятный, нейтральный
   - Громкость: Средняя

4. **join.mp3** - Пользователь присоединился к звонку
   - Длительность: 0.5-1 секунда
   - Характер: Восходящий тон, позитивный
   - Громкость: Низкая-средняя

5. **leave.mp3** - Пользователь покинул звонок
   - Длительность: 0.5-1 секунда
   - Характер: Нисходящий тон, нейтральный
   - Громкость: Низкая-средняя

## Где найти звуки

Вы можете использовать:
- [freesound.org](https://freesound.org) - Бесплатные звуковые эффекты
- [zapsplat.com](https://zapsplat.com) - Библиотека звуков
- [mixkit.co](https://mixkit.co/free-sound-effects/) - Бесплатные звуки
- Создать свои собственные звуки

## Формат

- Формат: MP3
- Битрейт: 128-192 kbps
- Частота дискретизации: 44.1 kHz

## Примечание

Убедитесь, что у вас есть права на использование звуковых файлов в вашем проекте.
